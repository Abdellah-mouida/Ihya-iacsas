# Morocco geography data

These region, province/prefecture, and city records were supplied by the project owner in `.agent/inbox/geo/regions.json`, `provinces.json`, and `cities.json` and normalized here by extracting each source file’s `data` array from its `{ success, message, data }` wrapper.

The supplied files do not identify an upstream source or include license metadata. Their upstream source and license are therefore unknown; confirm licensing before redistributing this data outside the project. No commune data is included or used. Coordinates are present only for cities, as supplied.
